Design the third block of the IZLI desktop admin back-office.
IZLI is a premium menswear brand inspired by Amazigh heritage, built as a hybrid between fashion commerce, editorial publishing, community participation, challenges, and collaborative community lab.

This prompt only covers:
- challenge management
- community lab management
- analytics
- system / settings screens

==================================================
1) GLOBAL CREATIVE DIRECTION
==================================================

Create a light premium admin interface with:
- warm beige / off-white backgrounds
- refined spacing
- soft cards and panels
- Indigo primary accents
- editorial serif only for major page titles
- clean sans-serif for the operational UI
- calm, serious, premium visual language

Avoid:
- generic SaaS dashboard feeling
- cold fintech aesthetics
- dark mode
- neon colors
- heavy enterprise UI density

==================================================
2) SCREENS TO DESIGN IN THIS PROMPT
==================================================

Generate a coherent desktop admin concept for:
1. Challenges List
2. Challenge Editor
3. Challenge Submissions
4. Challenge Results
5. Lab Projects List
6. Lab Project Editor
7. Calls for Contribution
8. Commerce Analytics
9. Community Analytics
10. Content Analytics
11. Team & Roles
12. Global Settings
13. Audit Log

==================================================
3) CHALLENGES LIST
==================================================

Design a challenges management page.

Include:
- challenge cover
- title
- status

- dates
- category or type
- CTA create challenge

Use sample challenge titles such as:

The page should feel like a cultural participation program dashboard, not a giveaway contest list.

Design a complete challenge editor.

- Overview
- Brief & Intention
- Rules & Eligibility
- Submission Format
- Timeline
- Rewards / Outputs

- Publishing

- allowed formats
- submission rules
- deadlines
