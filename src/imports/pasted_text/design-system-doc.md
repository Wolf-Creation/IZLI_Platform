PROJECT EVOLUTION

The current IZLI Platform already contains two connected applications.

• IZLI Website
• IZLI Admin

Both applications already share the same Design Language.

The Admin currently contains a menu item named

Components

Rename this menu to

Design System

Do NOT redesign the existing Website.

Do NOT redesign the existing Admin.

Do NOT regenerate current pages.

Do NOT modify the existing Design Language.

Do NOT replace current UI components.

The objective is to transform the existing Components page into the official IZLI Design System.
