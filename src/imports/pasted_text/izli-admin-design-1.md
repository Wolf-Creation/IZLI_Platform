Design the second block of the IZLI desktop admin back-office.
IZLI is a premium menswear brand inspired by Amazigh heritage, built as a hybrid between fashion commerce, editorial publishing, community participation, challenges, and collaborative community lab.

This prompt only covers:
- website & content CMS
- journal / stories
- community member and contribution management

==================================================
1) GLOBAL CREATIVE DIRECTION
==================================================

The admin must feel:
- premium
- light
- warm
- editorial
- calm
- serious
- culturally deep
- not like a generic SaaS dashboard

Use a premium light UI with:
- warm beige / off-white backgrounds
- soft cards and panels
- Indigo as primary accent
- serif only for page titles and some editorial headings
- clean sans-serif for the rest of the UI

Avoid:
- dark mode
- flashy gradients
- startup / fintech / crypto aesthetics
- cold generic CMS visuals

==================================================
2) SCREENS TO DESIGN IN THIS PROMPT
==================================================

Generate a coherent desktop admin concept for:
1. Home Builder
2. Site Page Editor
3. Media Library
4. Stories List
5. Story Editor
6. Story Review Queue
7. Members List
8. Member Profile Admin
9. Contributions List
10. Contribution Detail

==================================================
3) HOME BUILDER
==================================================

Design a homepage builder for IZLI with modular content blocks.

Editable blocks should include:
- Hero
- Shop by Universe
- Featured Collection
- Featured Products
- Featured Story
- Challenge Spotlight
- Community Spotlight
- Manifesto Block
- Newsletter / CTA block

UI structure:
- block list with drag / reorder feeling
- preview cards for each section
- edit panel for each block
- clear relationship between commerce and editorial content
- clean publishing controls

The page should feel like a premium brand CMS, not a marketing automation tool.

==================================================
