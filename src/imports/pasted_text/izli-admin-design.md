Design a complete desktop admin UI for IZLI, a premium contemporary menswear brand inspired by Amazigh heritage and built as a hybrid between fashion commerce, editorial publishing, community participation, challenges, and collaborative community lab.

This prompt only covers:
- global app shell
- overview / dashboard
- commerce flows and commerce management screens

==================================================
1) GLOBAL CREATIVE DIRECTION
==================================================

Create a light premium admin interface with a calm, refined, editorial tone.

The UI must feel:
- premium
- minimal but not empty
- soft, warm, clear
- structured and serious
- brand-led rather than startup-led
- visually close to a museum archive system + editorial CMS + fashion commerce admin
- operationally efficient

Avoid:
- flashy SaaS dashboards
- dark mode
- neon accents
- glassmorphism
- crypto / AI startup clichés
- cold enterprise dashboard aesthetics

==================================================

==================================================

Use the IZLI palette translated into a premium clear admin interface.

Core colors:
- Indigo #1E2F44
- Washed Indigo #506681

- Deep Charcoal #2E2E2E
- Clay Brown #8C6B52
- Sage Green #7D8470
- Sand Taupe #B7AA91
- Ink Black #111111

Recommended usage:
- main app background: warm light beige / off-white based on Linen Beige
- cards and panels: soft warm surfaces
- borders: taupe / beige grey
- primary actions and selected states: Indigo
- secondary accents: Washed Indigo and Clay Brown

Typography:
- elegant editorial serif for page titles only
- clean sans-serif for the full UI
- serif only for page titles and hero dashboard headings
- sans-serif for tables, forms, nav, filters, metadata and buttons
